🛡 SOC Platform – Cyber Threat Monitoring

A lightweight Security Operations Center (SOC) dashboard built with Python and Streamlit to visualize cyber attacks, analyze security events, and simulate threat monitoring in real time.

⸻

📌 Overview

This project demonstrates how a basic SOC monitoring platform can be implemented using Python and modern data visualization tools.

The dashboard helps security analysts observe attack activity, detect suspicious behavior, and understand global cyber-attack patterns.

⸻

⚙️ Features
 • 🌍 Global Threat Map
Visualize attack sources and paths on a world map.
 • 📈 Attack Timeline
Track how attacks evolve over time.
 • 🚨 Detection Alerts
Detect suspicious patterns such as repeated attacks from the same IP.
 • 🧠 MITRE ATT&CK Mapping
Map attack types to relevant MITRE techniques.
 • 🌐 Threat Intelligence Feed
Simulated threat intelligence sources.
 • 📊 Attack Distribution Analytics
Identify the most common attack types.
 • 📄 Security Logs Viewer
View and analyze raw security event logs.
 • 🎛 Threat Filters
Filter events by attack type or risk level.
